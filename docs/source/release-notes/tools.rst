Snapdragon Profiler Power Profiling Information
------------------------------------------------
This provides comprehensive instructions for collecting system power profiling information for CPU/GPU/NPU using the Snapdragon Profiler.

**Requirements:**

- Snapdragon Profiler Version: 2025.7 or later (available via Qualcomm Package Manager)
- Device: Snapdragon 8 Elite Gen 5 (must be rooted and SELinux disabled)


Step 1: Launch Snapdragon Profiler and Connect to Device

.. image:: /_static/tools/step1.jpg
   :width: 800px

Step 2: Select “Realtime Performance Analysis”

.. image:: /_static/tools/step2.jpg
   :width: 800px


Step 3: Enable Power Profiling Information
Double-click to select the Power Profiling Information.

.. image:: /_static/tools/step3.jpg
   :width: 800px
